# 微信公众号文章拆解与重写原则

## 1. 核心底线 (Core Boundaries)
*   **保留核心思想**：必须完整保留原讲稿中的思想体系、底层逻辑、对现实的辛辣评价与讽刺等核心内容，保障思想体系的逻辑链条清晰完整。
*   **坚守词汇准确性（玄学词汇处理底线）**：虽然总体要求尽量减少玄学描述，但**当某些道理必须依赖特定的玄学词汇（如：截教、阐教、因果、大爱等）才能准确表达时，坚决不可更改词汇**。绝不能为了通过平台审核或迎合大众口味，而强行替换导致改变原有核心含义，或使用错误、似是而非的描述方式。

## 2. 内容净化 (Content Purification)
*   **删除商业推广**：坚决剔除所有关于法器价格、销售信息、训练营推广、服务推销等直接或间接的商业变现内容。
*   **零商业暗示**：文章中严禁出现任何暗示作者提供商业服务的语句。包括但不限于：「我们为客户提供」、「我们接待过一个客户」、「我们的核心学员」、「我们的粉丝」、「十年财运图」、「年运卦」、「洗灵」、「喜灵」、「疗愈」、「静心符」、「请符」、「法事」等一切具体商业服务名称。文章定位是**纯粹的智慧分享与故事讲述**，而非服务商视角。若需引用案例，使用「有一个人」、「曾经见过一个例子」等中性表达。
*   **【绝对禁止】组织叙事者视角（全文适用）**：文章**全文任何位置**不得以"我们"或"我"作为叙述主体，尤其禁止以下模式：「我们经常发现」、「我们发现」、「我们有些客户」、「我一直强调」、「我要分享」、「我发现」、「我们常说」等。案例与理论解释须以纯粹的旁观者/分析视角描述，如「有人曾经历过这样的情况」、「俗语说”、“民间常讲”等无主语或客观表达。
*   **【绝对禁止】隐性组织归属感**：严禁任何以"我们"为主语、暗示作者隶属于某个提供产品或服务的组织的措辞。包括但不限于：「靠我们的一张符」、「我们的产品」、「我们的系统」、「加入我们」、「在我们这里」、「我们能帮你」等。凡是涉及某种工具、方法、规律的论述，应以**泛化的第三人称或无主语陈述**方式表达。
*   **删除组织运营细节**：删除一切收费标准、客户管理数据、内部人员配置、业务流程等组织内部视角的细节信息。
*   **【绝对禁止】原创性伪装**：文章必须以**独立原创稿件**的姿态呈现。严禁出现任何暴露内容来源于音频、讲稿、课程的措辞，包括但不限于：「原讲稿中提到」、「讲稿中」、「老师说」、「课程里提到」、「听到这段话」、「录音中」等。写作视角应是作者自己的深度洞察与分析，而非对他人内容的转述。
*   **剥离过度玄学外壳**：对于**非必要**的玄学描述（如过度渲染天珠、法器、鬼王、高维位面大战、前世今生细节等），在不影响核心道理表达的前提下进行删减。提倡将其精华提炼转化为底层的心理学规律、社会学法则或认知升级（心脑力）的心法法则。

## 3. 语气与视角 (Tone & Perspective)
*   **【新增指令】受众语气柔和与客观**：论述因果业力或负面现象时，绝对避免使用类似“你之前的滥情、贪婪或者坑蒙拐骗”这种直接把读者当做反面教材的刺耳、爹味或指责性语言。请改用第三人称客观描述（例如：“当一个人的负面行为积攒到临界点……”），或者采用共情、温和、客观分享的语气。永远不要用说教、居高临下的态度攻击读者。
*   **客观冷静的高维视角**：采用「第三方资深观察者」、「高维认知拆解者」或「心理学/社会学深度分析师」的口吻。文章应当像是一篇具有深度洞察的专栏文章，冷静、客观，但直击痛点。
*   **严格去内部化**：坚决避免使用第一人称（如「我」、「我们系统」）或组织内部人员讲话的视角。以此避免让外部读者产生距离感或误以为是推销。
*   **忌用说教式互动**：彻底摒弃讲师对学员说话的直播模式（绝对不能出现「大家听到的扣个1」、「同学们注意了」等）。改为了用提问、情境代入的方式与读者互动，例如：「你有没有经历过……」、「很多人都会陷入这种误区……」。

## 4. 叙事结构与篇幅拆解 (Narrative Structure & Length)
*   **篇幅拆解法则（10-14裂变）**：由于原始讲稿信息量巨大，**严禁将整篇讲稿压缩成一篇长文**。必须对单篇讲稿进行深度拆分，提炼出 10-14 个独立的核心知识点或完整逻辑闭环，将其分别扩写为 10-14 篇独立的公众号文章。
*   **单篇长度适中**：拆解后的每一篇文章必须篇幅适中（适合微信公众号的阅读节奏，通常在1500-2500字左右的体感，不宜过长或过短），且每一篇都要有独立完整的主题、引入、论述和结尾。
*   **标题规范**：
    *   **禁止「四字前缀_」格式**：绝对不能用「顶级认知_xxx」、「周期红利_xxx」这类格式。直接用完整的描述性标题，例如：「为什么那些神算子最后都坑了你？」
    *   **标题禁词**：标题中禁止出现「修行」、「玄学」、「师门」等字眼，改用「规律」、「真相」、「底层逻辑」、「认知」等大众化词汇。
    *   **草稿箱标题规定（无数字规则）**：上传或生成的最终文章标题**绝对不要包含任何前置数字编号（如“11-06”）**。虽然文件名可以是 `11-06_文章名.md`，但提供给草稿箱的文章标题必须是纯粹的名字（例如“神圣愿景难敌养命碎银”）。
*   **【极其严峻的排版禁忌（红框与序号bug警告）】**：
    *   **禁止输出 `# 文章标题`**：生成的 Markdown 正文中，**绝对不允许**把标题作为一级标题（# 标题）再写一遍。正文直接从内容第一句开始。由于标题会在草稿箱里单独填写，正文里重复写会造成“红框重复并列”问题。
    *   **禁止输出封面图语法**：**绝对不允许**在文中输出 `![封面配图：XXX](...)` 或任何图片占位符。不仅会影响排版，还会造成极差的视觉体验。
    *   **序号列表必须换用中文顿号格式**：由于微信编辑器对 Markdown 的数字+空格序号（如 `1.  **文本**`）存在严重的解析 bug（会导致换行后只剩数字），**必须使用** `1、**文本**` 或 `一、**文本**` 这种不带标点英文句号的格式。严禁使用 `1.` 生成标准的 Markdown 列表。
    *   「修行」、「玄学」、「师门」、「仙家」等带有宗教/神秘学色彩的词汇。
    *   「十年财运图」、「年运卦」、「洗灵」、「疗愈」等具体商业服务项目。
    *   开头应以社会热点、职场困境、家庭关系、人性观察或普世现象切入。
*   **隐晦开局与深度剖析（审查规避与深度并行）**：
    *   **开头开局（隐晦包装）**：文章开头及标题等显眼位置**必须尽量减少明显的玄学名词，采用更易被大众接受的泛心理学、社会规律或隐晦的词汇**作为引子。避免因为敏感词触发审核雷区。
    *   **中段深拆（保留核心玄学事实）**：在进入深度逻辑剖析时，文章的中后段**必须原汁原味地保留核心玄学概念（如「天道抹杀」、「因果业力」、「系统修正」、「功德福报」等）**。绝不能为了迎合大众而自行曲解或稀释原意，保障对资深读者的洞察力。
    *   **原真案例引入**：在引入观点时，如果要用案例，可以直接提炼原讲稿中老师提及的案例进行适度的隐晦包装，**绝对禁止生硬编造虚假的「世俗商业」故事。**
*   **专属封面图**：每篇文章必须依据其主旨大意，在文章开头配上一张具有视觉冲击力、符合高维商业/心理学调性的封面配图，**图片比例要求为 1.35:1**。
*   **降维打击与现实落脚**：保留立意极高的「降维打击」爽感，将最终落脚点放在个人的心智成熟、抵御现实风险（如经济下行）、以及处理复杂人际关系等痛点上。
*   **序号对应**：生成的文章序号必须与对应的录音稿编号一致（如 11 号录音稿生成的文章应为 11-01, 11-02 等）。
